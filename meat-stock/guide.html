🛒 รับเนื้อสด
ใช้แท็บนี้เมื่อ: รับเนื้อดิบจาก supplier เท่านั้น — เนื้อตุ๋น/หั่นแล้วไม่ใช้ตรงนี้
กรอกวันที่รับเข้า + เลขที่ใบซื้อ/ใบส่ง
กด "+ เพิ่มรายการเนื้อ"
เลือกประเภทเนื้อ → เลือกวัน Lot → ใส่จำนวนถุง
ชั่งแล้วกรอกน้ำหนักทีละถุง
⚠️ หน่วยเป็นกรัม (เช่น ถุงละ 2340 ไม่ใช่ 2.34) — ระบบรวมยอดให้อัตโนมัติด้านล่าง
กด ✅ บันทึกรับเนื้อสด
เสร็จเลย เนื้อเข้าคลัง A พร้อมใช้งานทันที
2
🔥 หม้อตุ๋น
หน้านี้เป็นกระดาน 3 ช่อง: 📋 วางแผน → 🔥 กำลังต้ม → ✅ เสร็จวันนี้ — หม้อจะเลื่อนช่องเองตามสถานะ
ก) เปิดหม้อ (เริ่มต้ม)
กด "🔥 เปิดเนื้อใหม่"
(ถ้าแค่จะวางแผนไว้ก่อนยังไม่ต้ม กด "📝 วางแผนเนื้อ" แทน — จะยังไม่ตัดสต๊อกถุง)
เลือกกะ (เช้า/บ่าย/เย็น) — ระบบเดาให้อัตโนมัติตามเวลา
เลือกรายการเนื้อสด → แตะเลือกถุงที่จะเอาเข้าหม้อ
แตะได้หลายถุง แตะซ้ำเพื่อยกเลิก — ตัวเลขด้านล่างบอกจำนวนถุง+น้ำหนักรวมที่เลือก
กด "🔥 ส่งเข้าหม้อ" — การ์ดจะไปอยู่ช่อง "กำลังต้ม"
ข) ปิดหม้อ (ต้มเสร็จแล้ว)
แตะการ์ดในช่อง "กำลังต้ม" → กด "✏️ ปิดหม้อ"
เลือกชื่อเนื้อตุ๋น (ผลผลิต) + ใส่จำนวนถุง → ชั่งแล้วกรอกน้ำหนักรายถุง
ถ้ามีเศษ/ของเหลือ (waste) กรอกน้ำหนัก + หมายเหตุ เช่น กระดูก หนัง ไขมัน
บางชนิดเนื้อจะมี By-product ให้กรอกเพิ่ม (เช่น น้ำต้ม) — ระบบจะโชว์ให้เองถ้ามี
เช็คตัวเลข Yield ที่ระบบคำนวณให้ แล้วกด "✅ ปิดหม้อ"
ปกติ yield อยู่ราว 65–75% — ถ้าต่ำ/สูงผิดปกติมาก ให้ทักไทน์เช็ค
🚫 กดผิดหม้อ / เปิดหม้อผิด → ใช้ปุ่ม "🚫 ยกเลิกหม้อ" ในหน้าปิดหม้อได้ (ถุงจะกลับเข้าสต๊อกเหมือนเดิม)
3
♻️ แปรรูป / รีแพ็ค
💡 แปรรูป = เอาถุงที่มีอยู่แล้ว (input) → เปลี่ยนเป็นถุงใหม่ (output) — ถุง input จะถูกปิดสถานะอัตโนมัติ
ประเภทใช้เมื่อไหร่
ครัวกลางตัดแบ่งเนื้อออกเป็น SKU ใหม่ พร้อมขาย
รีแพ็คเปลี่ยนขนาดถุง — item เดิม เช่น [500g] → [75g] หลายถุง
ผสมรวมหลายถุงเป็น 1 ถุงใหม่
เลือกวันที่ + เลือกประเภท (ครัวกลาง/รีแพ็ค/ผสม)
กด "+ เพิ่มถุงต้นทาง" → แตะเลือกถุงที่จะเอามาแปรรูป
เลือก SKU ผลผลิต (output) → ใส่จำนวนถุงใหม่ → กรอกน้ำหนักรายถุง
ถ้ามีเศษเหลือจากการแปรรูป กด "+ เพิ่มรายการเศษ" กรอกเพิ่ม
กด ✅ บันทึกแปรรูป — เสร็จ ระบบปิดถุงเก่า+เปิดถุงใหม่ให้เอง
4
📊 สต๊อกปัจจุบัน / 📋 ประวัติ
✅ สองแท็บนี้ ดูอย่างเดียว ไม่ต้องกรอกอะไร
📊 สต๊อกปัจจุบัน
ดูยอดคงเหลือทั้งหมด (จำนวนถุง/กก.) แยกคลัง A (เนื้อสด) / คลัง B (เนื้อตุ๋น) — เห็นทันที ไม่ต้องรอใครอัปเดต
📋 ประวัติรับเนื้อ
เลือกวันที่ → ดูว่าวันนั้นรับเนื้ออะไรเข้ามาบ้าง กี่ถุง กี่กก.
5
🚛 ส่งออก (NT / FS) — ออกใบนำส่ง
⚠️ ส่งออกเนื้อ อยู่ที่ Hub → ออกใบนำส่ง (ไม่ใช่ในแอป Meat Stock) เพราะใบนำส่งรวมทั้งเนื้อ + ของครัวใน 1 บิล
เปิด Hub → กด "🚛 ออกใบนำส่ง"
เลือกวันที่ส่ง / ปลายทาง / เลขที่ใบนำส่ง
กด "+ เพิ่มรายการเนื้อ" → เลือก SKU → "เลือกถุง" → แตะถุง (lot chip)
ถ้ามีของครัวด้วย กด "+ เพิ่มรายการ Non-meat" → เลือก item → ใส่จำนวน
เช็ค preview ด้านล่าง → กด "🚛 บันทึกส่งออก" → กด "🖨 พิมพ์"
6
❓ FAQ — ถามบ่อย
Q: กรอกผิด แก้ยังไง? ยังไม่มีหน้าแก้ไขเอง — แจ้งไทน์หรือฝ่าย Platform ให้ช่วยแก้
Q: chip ที่แตะเลือกถุงคืออะไร? แต่ละ chip = 1 ถุง แสดงเลข CW (r123) + น้ำหนัก — แตะเพื่อเลือก/ยกเลิก สีน้ำเงิน = เลือกแล้ว
Q: ถ้าเน็ตหลุดระหว่างกรอก ทำยังไง? ระบบต้องใช้อินเทอร์เน็ต — รอสัญญาณกลับมาก่อนค่อยกรอกใหม่ อย่าปิดหน้าจอถ้ายังไม่กด "บันทึก"
Q: ถุงที่เป็น [75g] [500g] ชั่งน้ำหนักยังไง? กรอกน้ำหนัก nominal ตามที่เขียนไว้ (75 หรือ 500 กรัม) — ไม่ต้องชั่งจริงทุกถุง
Q: ทำไม yield ในหน้าปิดหม้อเตือนสีแดง/เหลือง? ระบบเทียบ % ผลผลิตตุ๋น กับ range ปกติ (65–75%) อัตโนมัติ — ถ้าเตือน ให้เช็คน้ำหนักที่กรอกอีกรอบก่อนกด "ปิดหม้อ"
