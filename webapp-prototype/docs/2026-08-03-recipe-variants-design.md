# Recipe Family และ Protein Variants — Design

## เป้าหมาย

เพิ่มความสามารถให้สูตรแม่หนึ่งสูตรมีตัวเลือกเนื้อหลายแบบ โดยไม่คัดลอกส่วนผสมและขั้นตอนที่ใช้ร่วมกัน และรองรับหนึ่ง Variant ที่ประกอบด้วยเนื้อหรือชิ้นส่วนมากกว่าหนึ่งรายการ

## แบบที่เลือก

```text
Recipe Family: กะเพรา
├── Base ingredients + Base SOP
├── Variant: หมูสับ
│   └── หมูบด 120 g
├── Variant: เนื้อรวม
│   ├── เนื้อใบพาย 70 g
│   └── เนื้อน่องลาย 50 g
└── Variant: ไก่
    └── สะโพกไก่ 120 g
```

ผู้ใช้ต้องเลือกรูปแบบเมนูอย่างชัดเจน:

- `single` — ส่วนผสมคือสูตรสมบูรณ์ มี Sellable Item/SKU เดียว
- `variant` — ส่วนผสมคือส่วนร่วม และแต่ละ Variant เป็น Sellable Item/SKU แยก

- ส่วนผสมร่วมและวิธีทำอยู่ที่สูตรแม่
- แต่ละ Variant มีชื่อ ราคาขาย สถานะ draft/active/inactive และรายการวัตถุดิบผันแปรของตัวเอง
- แต่ละ Variant มี Metadata ได้แก่ code, Internal SKU และสถานะ
- Routing แยกเป็นจุดครัว สาขา ช่องทางขาย และ External SKU
- หนึ่ง Variant เพิ่ม/ลบวัตถุดิบผันแปรได้หลายรายการ
- ไข่ดาว เพิ่มข้าว และของเพิ่มทั่วไปเป็น Modifier ไม่ใช่ Variant

## UX

- เพิ่ม section “ตัวเลือกเนื้อ / Recipe Variants” หลังส่วนผสมสูตรแม่
- ผู้ใช้เพิ่ม/ลบ Variant และเพิ่ม/ลบชิ้นส่วนเนื้อภายใน Variant ได้
- มีปุ่มโหลดตัวอย่างกะเพราเพื่อสาธิต Variant เดี่ยวและ Variant เนื้อรวม
- Food Cost Preview มีตัวเลือกว่าจะคำนวณสูตรแม่ร่วมกับ Variant ใด
- Print Center แสดง Variant ของสูตรปัจจุบันเป็นรายการสูตรแยก เพื่อเลือกพิมพ์ได้ทีละแบบหรือหลายแบบ
- SKU & Routing Sheet แสดง mapping ของ Sellable Item ต่อช่องทางและสาขา

## กติกาข้อมูล

- Variant ที่ไม่มีชื่อใช้ชื่อ “ตัวเลือกที่ N” เฉพาะใน mock UI
- รายการเนื้อที่ไม่มีทั้งชื่อและปริมาณจะไม่ถูกนำไปคำนวณหรือพิมพ์
- หากมี Variant อย่างน้อยหนึ่งรายการ สูตรปัจจุบันใน Print Center จะแตกเป็นเอกสารต่อ Variant
- เฉพาะ Variant สถานะ active เท่านั้นที่เป็นสูตรขายใน cost selector, Print Center และ Routing
- หากผู้ใช้เลือกโหมด variant แต่ไม่มี active Variant ระบบเตือนและไม่เปลี่ยนกลับเป็น single อัตโนมัติ
- การสลับกลับเป็น single ซ่อนแต่ไม่ลบ Variant ที่กรอกไว้
- การแปลงหน่วยของวัตถุดิบ Variant ใช้ Measurement Knowledge กติกาเดียวกับส่วนผสมสูตรแม่ และห้ามเดาค่าที่ไม่มี

## ขอบเขต

เป็น static mock เท่านั้น ไม่มีการบันทึก ราคาวัตถุดิบจริง POS SKU ฐานข้อมูล หรือการเผยแพร่จริงให้สาขา
